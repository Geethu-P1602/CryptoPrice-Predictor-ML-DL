#  CryptoPrice-Predictor-ML-DL

An end-to-end Machine Learning & Deep Learning project for analyzing and predicting cryptocurrency closing prices using real-time financial data from Yahoo Finance.

---

##  Features
-  Exploratory Data Analysis (EDA) on crypto data
-  Visualization of trends and patterns
-  Machine Learning models for price prediction
-  Deep Learning models (LSTM/ANN) for improved accuracy
-  Real-time data fetching using yfinance

---

##  Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- TensorFlow / Keras
- yfinance

---

##  Files Description
- `crypto_analysis.ipynb` → Data analysis, visualization, insights
- `crypto_prediction.ipynb` → ML & DL models for predicting closing price

---

##  Workflow
1. Data Collection using yfinance
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Model Building (ML & DL)
6. Prediction & Evaluation

---

##  Objective
To predict cryptocurrency closing prices using historical data and advanced machine learning techniques.
